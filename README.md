# youtube-playlist-subtitles

Скачивает **только уже существующие** субтитры YouTube из плейлиста (авторские + автоматически созданные YouTube).

- Не скачивает видео и аудио
- Не использует Whisper
- Не создаёт новые субтитры
- Работает полностью через GitHub Actions
- Можно запускать с телефона

## Как пользоваться (с телефона)

1. Откройте этот репозиторий: https://github.com/simaklawyer/youtube-playlist-subtitles
2. Перейдите во вкладку **Actions**
3. Выберите workflow **Download existing YouTube subtitles**
4. Нажмите **Run workflow**
5. Вставьте ссылку на плейлист:
   ```
   https://www.youtube.com/playlist?list=...
   ```
6. В поле `languages` укажите нужные языки (по умолчанию `ru,en`)
7. Нажмите **Run workflow**
8. Дождитесь завершения (обычно несколько минут)
9. Откройте выполненный запуск → раздел **Artifacts** → скачайте `youtube-subtitles`
10. Распакуйте ZIP на телефоне

В архиве:
```
output/
├── 001 - Название видео.ru.srt
├── 002 - Название видео.en.srt
└── ...
report.txt
```

В `report.txt` видно, какие видео имели субтитры, а какие были пропущены.

## Что именно скачивается

| Параметр | Что делает |
|----------|------------|
| `--write-subs` | Авторские субтитры |
| `--write-auto-subs` | Автоматические субтитры YouTube |
| `--skip-download` | Видео и аудио **не** скачиваются |

Если нужны **только** авторские субтитры (без автоматических), отредактируйте файл `.github/workflows/download-subtitles.yml` и уберите строку `--write-auto-subs`.

## Языки

Примеры значений для поля `languages`:

- `ru` — только русский
- `en` — только английский
- `ru,en` — русский и английский (по умолчанию)
- `ru.*` — русский + региональные варианты

## Важно

- Artifact хранится **7 дней**, потом удаляется. Скачивайте сразу.
- Репозиторий публичный — не коммитьте в него cookies, токены или чужие субтитры.
- Результаты не коммитятся в Git, они только во временном artifact.
- Для больших плейлистов (сотни видео) время выполнения может вырасти.

## Технические детали

Workflow использует:
- `yt-dlp` для получения субтитров
- `ffmpeg` только для конвертации в SRT
- Ubuntu-latest runner GitHub Actions

Никаких API-ключей, Whisper, CUDA и т.п. не требуется.
